# Security reporting

Please do not disclose vulnerabilities, exploit archives, credentials, or
personal information in public issues.

Use GitHub's **Security -> Advisories -> Report a vulnerability** when private
vulnerability reporting is enabled. If that option is not available, contact
the maintainer privately through the support contact published at
https://app.myers.io/gaelic_companion before sending sensitive details.

Include the app/build version, iOS version, expected and observed behavior,
and minimal reproduction steps. Use original synthetic files rather than
publisher recordings or your personal library.

Security fixes target the current release and `main`. No response-time or
older-version support guarantee is offered.

Before public launch, the maintainer must enable private vulnerability
reporting and verify that the support page has a working private contact route.
